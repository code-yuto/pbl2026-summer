# Report Images / レポート用画像

Place the following image files in this folder. `report-final.md` already
references them by these exact names, so once a file is saved here with the
matching name, it will automatically appear in the report — no further Markdown
editing is required.

これらのファイル名を参照しているため、同じファイル名でここに保存するだけで
レポートに自動的に表示されます(Markdownの追加編集は不要です)。
